# Case studies

Three incidents from the private codebases this repository was extracted from.
Each one is here because it produced a mechanism you can find in this repo, and
each is written in the same four parts: what happened, why it was invisible, what
it cost, and what now stops it.

Names, systems and identifiers are removed. The numbers are not: a case study
that has been rounded into a moral is a moral, and morals do not change anyone's
behaviour. If a number here looks oddly specific, that is the point.

| # | Case | The mechanism it produced |
|---|---|---|
| 1 | [A guard that could not fail](01-the-vacuous-guard.md) | `fixtures/`, and the rule that a guard needs a failing input |
| 2 | [A window that inverted a verdict](02-the-window-that-inverted-a-verdict.md) | `measurement-discipline` §1.1, `deploy-verify-run.md` |
| 3 | [The setting that lived in another table](03-the-setting-in-another-table.md) | `the-second-instance`, and "name the column in the sentence" |
